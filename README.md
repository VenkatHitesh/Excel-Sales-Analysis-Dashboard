# Excel Sales Data Analysis Dashboard

## Project Overview
This project focuses on analyzing sales data using Microsoft Excel to identify meaningful business insights and present them through an interactive Executive Summary Dashboard.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Analysis

## Workbook Structure
- **Orders:** Raw sales and order data containing 8,406 records.
- **Other Info:** Region and customer segment information.
- **Pivot Tables & Pivot Charts:** Data summarization and visual analysis.
- **Dashboard:** Executive Summary Dashboard presenting key sales insights.

## Project Objectives
- Analyze sales and profit performance.
- Understand regional performance.
- Evaluate customer segment performance.
- Summarize business data using Pivot Tables.
- Present insights through interactive visualizations.

## Key Skills Demonstrated
- Excel Data Analysis
- Data Summarization
- Pivot Tables and Pivot Charts
- Dashboard Creation
- Data Visualization
